## Running the programs

Install Python 3 and clone the repository:

```bash
git clone https://github.com/Harshad8623/Python-Learning-Journey.git
cd Python-Learning-Journey
```

Open an individual exercise folder and run the appropriate script with `python filename.py`. Some exercises may require user input or additional packages; check the script before running it.
